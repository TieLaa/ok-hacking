## 五、经理帮助 vs 暴击训练：数字对比（用户提问）

**触发机制确实同源**：装备用得多 → 累积经验 → 满了出现金边/彩边 → 训练暴击；经理一起训练 → 累积经验 → 触发「经理的帮助」（加强训练）。

**单次数值**（全量日志，`logs/ok-script*.log`）：

| | 暴击训练（彩框） | 经理的帮助（加强训练） |
|---|---|---|
| 单次总属性 | 比同周普通训练多 **+15.5 / +65.6 / +22.0 / +24.6**（第 3/4/5/6 周），中位 ≈ **+23**，均值 ≈ **+32** | +30 档 = 2 属性 ×30 = **60**；+36 档 = **72**（实测一屏「+18 +18 +36」= 72） |
| 成功率 | 必然触发 | 65%~100%，日志自带 EV：每题 12~25/属性 |
| 期望值 | ≈ +23~32 | **39~72**（按成功率折算） |
| 触发频率 | 14 次 / 287 次训练 ≈ **5%** | 47 次 / 287 次训练 ≈ **16%** |

**结论**：机制同级，数值不同级 —— **经理帮助单次约为暴击的 2 倍，触发频率约为 3 倍**。所以：

- 现在 `W_MANAGER 2.1 < W_GOLD 2.2 < W_COLOR 2.3` 的排序与实测相反；
- 金框（未满）在数据里**没有任何独立增益样本**，它更像「快要暴击」的预告，不该单独给权重；
- 若要改，建议三者同级或经理略高：`W_MANAGER 2.1`、`W_GOLD/W_COLOR 2.0~2.1`。

**注意**：暴击只有 14 个样本，且暴击往往伴随「装备满」，`+23` 里可能有一部分是装备本身的基础增益，不是暴击额外给的。
