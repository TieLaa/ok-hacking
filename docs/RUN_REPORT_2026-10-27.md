- 文件：`weekend.py` → `handle_go_out` / `handle_weekend` / `handle_park`
- 判据统一为「**有「出行」= 周末首页；没有 = 地图/内页**」

### 3. 恢复类扭蛋评分太低，并列时被丢掉

- 用户截图（第6周周六 45/130）：三选一里「精力恢复++」（金/100币/带队友，
  立刻恢复90，之后每天30×4天）和「运控增加++」同为 141 分，
  `max()` 取第一个 → 买错。
- 新增 `parsers.stamina_recover()`：只认 `恢复<N>精力` / `恢复<N>点` /
  `每天恢复<N>点…持续<D>天`；含「清空/消耗」一律 0。
  该卡算出 90 + 30×4 = **210 点**。
- 评分加成：`min(恢复量, 体力上限-当前体力) × 0.5`
  → 45/130 时 +42 分，恢复卡 183 > 141；满体力 room=0 不加分。
- 文档：`docs/RULES.md` 第 2 节已补「恢复精力卡的关键字」。
