## 周五「额外周末」（野上泷天赋）

- 出现条件：`第N周 星期五` 的训练日主界面，右侧多出一个「出行」按钮。
  这是天赋触发的**额外周末**，当天仍可训练/休息，也可以直接出行去户外地图。
- 实测：2026-10-30 16:05，第 1 周 星期五，体力 82/130，零用钱 169。

界面要素（1549x871）：

| 位置 | 内容 | 备注 |
|---|---|---|
| 顶栏左 | `第1周` `星期五` | 日期解析同平时 |
| 顶栏中 | `82/130`、`169` | 体力 / 零用钱 |
| 左上 | `3天 赢得比赛` | 比赛倒计时 |
| 右上 | `商店`（图标+文字） | y≈0.21h，和比赛日的商店入口同一位置 |
| 右侧竖排 | `出行`(y≈0.55h)、`休息`(y≈0.72h) | x≈0.85~0.95w |
| 右下 | `训练`（黄色大按钮） | y≈0.83h |
| 底部 | 六维属性面板 | 投射/弹跳/运控/体能/防守/意识 |
| 中间 | 队长立绘 + 台词 | 台词会出现「今天可以出行哦！要不…」 |

操作：点**右侧整词**「出行」→ 进入户外地图（和周六/周日同一张地图）。

坑：

1. 台词里有「今天可以出行哦！要不…」，`click_text("出行")` 会命中这句台词
   （日志 `left_click 今天可以出行哦！要不 (950, 182)`），点了没有反应。
   必须限定 `x > 0.75w` 的整词「出行」。
2. 一天只能出行一次，否则「出行 → 地图 → 退回首页」打转；
   `weekend_state()["outing_done"]` 记录，非周末再遇到就直接返回主界面。

代码：`handlers/weekend.py: handle_go_out`、`parsers.py: weekend_state`。

扭蛋流的周末口径（因为这个天赋，周五也算周末）：

- 周五 / 周六 / 周日：只进「步行街（扭蛋）」或「餐厅」。
- **钱 > 300 → 先进步行街消费**（钱多就该花掉，别留到最后剩一堆）。
- 钱 ≤ 300 时看队友：**两边都有队友 → 步行街**；只有一边有队友 → 去那一边；
  **都没队友**：周五 / 周六 → 餐厅赚钱；周日 → 步行街消费。
- 地图上步行街上方出现彩色爆炸标签 **「扭蛋增强！」** 时：不管钱和队友，
  直接进步行街（最高优先级）。
- 去了步行街但**没消费**（没钱 / 没买到）→ 再去餐厅打工；买到东西就不去了。
- 餐厅打工：**队友多**的优先；一样多选右边（耗精力那张）；**右边精力不够就选左边**。
- 代码：`constants.WEEKEND_PLAN`、`flow.weekend_priority`、
  `handlers/weekend.py: prefer_mate_venue / restaurant_order`。

## 周末地图的标记

| 标记 | 外观 | 含义 |
|---|---|---|
| 队友气泡 | 深藏青圆角块 + 1~2 个圆头像 | 该地点有队友（`venue_has_mate`） |
| 打折！ | 橙色爆炸标签，贴在地点左上方 | 该地点在打折（`venue_on_discount`） |
| **扭蛋增强！** | **彩色（蓝/紫/青渐变）爆炸标签**，贴在步行街左上方 | 步行街扭蛋加成，优先去（`prefer_mate_venue`） |
| 绿色定位针 | 绿色水滴图标 | 当前所在位置，不是可点入口 |

实测：2026-10-30 第 5 周星期五（野上泷额外周末），步行街有「扭蛋增强！」，
同时餐厅/公园各有一个队友气泡。

## 扭蛋购买界面（含「增强款」）

- 实测：2026-10-30 第 5 周星期五，体力 130/130，零用钱 375。
- 要素：
  - 标题 `请选择1个扭蛋`
  - 三张卡横排，卡头是一条品质色带（**金 / 紫 / 蓝**）
  - 每张卡**右上角**可能有黄色斜标签 `增强款`（艺术字，OCR 会读成「增强款」）
  - 每张卡**左上角**可能有队友标记（`!` + 头像；这一版是**深蓝底浅色头像**，
    不是旧版的橙色气泡，位置也更靠下 ≈0.29~0.34h）
  - 卡底部价格药丸被红字「打折」压着：`100 → 90`、`60 → 50`
  - 卡内说明里也会出现「增强 额外获得体能+14」，那不是标签
- 选择优先级（用户 2026-10-30）：**品质（金/紫）> 增强款 > 队友**。
  - 蓝卡默认不买（除非体力低时要买「清空精力」卡换属性）。
  - 同品质里先看右上角「增强款」，再看左上角队友标记。
- 代码：`parsers.py: read_gacha_cards / has_mate_badge`、`handlers/weekend.py: handle_street`。
