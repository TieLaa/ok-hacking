# 机制：风格与相克（速度 / 技巧 / 力量）

> 来源：用户 2026-10-28 口述 + 游戏内「请选卡」界面左下角三角图 + 角色详情页图标取色。
> 采集脚本：`tools/collect_ssr.py`（18 个 SSR 的风格/位置/技能已入库 `docs/roster/`）

## 一、三种风格与图标

| 风格 | 图标 | 取色特征（HSV 色相） |
|---|---|---|
| 速度 | 蓝色闪电 | H 90~130 |
| 技巧 | 绿色星星 | H 35~90 |
| 力量 | 红色拳头 | H ≤12 或 ≥165（橙红兜底 12~35） |

图标位置：**角色详情页右上角，名字右边那个圆标**。

## 二、相克关系

```
        力
       ↙   ↖
     技  ←→  速
```

- **力 克 技**（力被速克）
- **技 克 速**（技被力克）
- **速 克 力**（速被技克）

> 用户在「请选卡」界面左下角确认。数据里已写成 `counters` / `countered_by` 两个字段。

## 三、两处生效

### 1) 角色属性

每个角色固定一个风格，影响……（待验证：是影响对抗判定，还是只影响出牌）

### 2) **比赛内出牌**（2026-10-28 用户确认）

「请选卡」界面上：

- 三张**基础卡**（三分 / 突破 / 横撤）左上角各带一个 `技` / `速` / `力` 小标签
- 右侧**技能卡**（瞬步潜行等）同样带风格标签
- 对手侧显示 `???`（未知卡）

也就是说**出牌也走同一套相克**，不只是角色属性。做「比赛内自动出牌」时这是核心判据。
