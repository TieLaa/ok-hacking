# 2026-10-26 养成自动化修补报告

## 本轮改动

### 输入层

- 新增 `tools/abs_mouse.py`：绝对坐标 `mouse_event(MOVE|ABSOLUTE|VIRTUALDESK)` 一步到位，不用 `SetCursorPos`、不滑行。
- `tools/click.py` / `click_text.py` / `click_window.py` / `start_ok_task.py` / `test_bg_click.py` 全部改用 `abs_mouse`。
- 找游戏窗口统一校验 `UnityWndClass`，修掉浏览器攻略帖标题含「篮球少女」被误认的问题。
- `FLOW_COORDS` 按新 UI 实测更新；「自动选择 / 下一步 / 开始训练」改为按 OCR 文字框点击（队伍满员时面板会下移 40~50px）。

### 科目选择

- 只点有队友小人的科目；每次点击后**重新 OCR** 找按钮（选中科目会占住原来那一行，旧坐标会点错）。
- 新版 UI 小人图标在按钮右侧居中，旧版在右上角 -55px，`has_teammate_icon` 两种都支持。
- 预览统计：队友数 + 装备数 + 2×满经验（MAX）；彩虹边框只作 +1 辅助。
- 满经验器材显示 **MAX**，卡片/科目按钮带彩虹边框，训练结算出现「暴击训练!」。
- 科目页判据加「失败率」，防止商店右栏的「防守秘籍+/防守+40」被当成科目页（曾 400 步全耗在商店）。

### 周末

- 训练流周六先看商店：解析商品名/价格/剩余，买**买得起的最贵项**，优先「器材手册+」；钱不够就退出。
- 同一周只逛一次商店（`_shop_week`），防顶栏星期 OCR 抖动导致重复进店。
- 周六公园选「划船」（属性+，精力+30）；周日体力 <60 才野餐，否则继续划船。
- 实测：30~40 精力 → 划船 50 多 → 次日划船 90 多，不再满体力吃野餐。

### 事件

- 左右二选一：黄色/白底彩边按钮，解析「精力+10 / 50%概率 精力+30」，按 收益×概率 选，排除纯回精力。
- 竖向 3 选 1：白底圆角横条，默认第一个；要求右上「跳过」+ 白底横带 + 排除「下一步/下一场/跳过」等 UI 词。
- 训练事件全屏角色 + 右下白色 ▼：点 (0.96,0.93) 推进。
- 锦标赛对阵图（赛程已完成 4/5、距离下场比赛、下一步）：由 `handle_match_result` 点「下一步」。

## 已知限制

- 队友名字 OCR 偶发漏识别，单帧计数可能偏少；目前仍是单帧，后续可改成 2~3 帧取最大。
- 训练事件/长剧情的 ▼ 点击有时需要多拍才推进。
- 商店只买一件（买得起的最贵），不会在同一家店连续扫货。
- 「训练结果 / 恭喜获得 / 前两名晋级」这类结算页里「下一步」有时点不动，会空转；下次需单独加 handler（先点「确认」或点屏幕中央）。
