## 修复的 bug

1. **体力解析错**：OCR 把「第1周」的 `31` 和 `101/115` 粘成 `3101/115` → 解析成 31101。
   现在只取含 `/` 的文本框，正则限 1~3 位，且要求 `当前 ≤ 上限`。
2. **点击无效**：`SetCursorPos` 瞬移对这游戏无效（它按 raw input 相对位移采样）。
   改成 `mouse_event(MOVE, dx, dy)` 小步移动（每步 ≤12px）。
3. **窗口没真正置前**：`SetForegroundWindow` 被 Windows 静默拒绝，鼠标事件全打到别的窗口。
   修法：先 `keybd_event(VK_MENU)` 再置顶，`finally` 抬起 Alt。
4. **剧情 ▼ 误判**：周末地图底色是白的，白色占比也是 1.00，导致一直点地图。
   加了「周围一圈必须偏暗（mean < 135）」的条件。

## 启动/停止技巧（踩过的坑）

- **GUI 布局会变**：任务跑完后顶部展开「已完成」面板，任务卡整体下移，
  「开始」按钮从 `y≈89` 变到 `y≈470`。点之前先截图确认位置。
- ok-script 的 Qt 窗口对 `PostMessage` **时灵时不灵**，真实点击更稳（`tools/click_window.py`）。
- 点完 GUI 必须把游戏切回前台，否则执行器会因「窗口不可见」暂停。
- `TaskExecutor` 暂停时日志会打 `executor is paused sleep`，看到这句就是没在跑。
