## 三、本轮改动

### 1. `tools/start_ok_task.py`：排队必须核对任务名

- 旧逻辑只判断日志里有 `queued onetime_task` 就算成功——4 张任务卡都会打这行，
  点歪到示例卡同样"成功"（本局 09:44:35 实测）。
- 现在解析任务名，只有含 `训练循环`/`TrainingTask` 才算排上；排错直接报错退出（exit 2），
  不再往下试候选位置。
- 轮询从固定 1.6s 改成每个候选最多 4s（OK 刚启动头几秒点击会被吞）。
- 去掉「点完最小化 GUI + 抢游戏前台」：输入层已改后台点击，前台是谁都不影响落点。

### 2. `src/util/emergency_stop.py`：F8 轮询连续 3 拍确认

- 单拍 `GetAsyncKeyState` 就判定按下 → 手柄/输入法/其他软件转发的瞬时状态会误报
  （本局 09:47:17、上一局 00:39:05 各一次）。
- 改成连续 3 拍（0.05s × 3 ≈ 150ms）才触发；单拍只记 debug 日志。真按住 F8 ≥200ms 不受影响。
