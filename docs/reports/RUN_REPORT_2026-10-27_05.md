## 二、本轮修复：启动脚本改为 OCR 定位「开始」按钮

重启后第一次点「开始」又点歪到第 4 张卡（`Configuration Demo Task`）——这次任务名校验
把它拦下来了（exit 2，明确报「排上的是别的任务，请先停掉它再重试」），没有白跑。

根因：`CANDIDATE_Y` 是**窗口 1200x800 时的固定相对坐标**，而用户把 OK 窗口拖成了
1170x749，卡片行高随之变化，第一张卡的真实按钮在 y=89 之外。

修法：先用 OCR 找「训练循环」标题，再点同一行最右侧的「开始」按钮（窗口内相对坐标 +
当场读的窗口原点），失败才退回原候选坐标表。实测定位到窗口内 (1055, 89)，一次点中。
