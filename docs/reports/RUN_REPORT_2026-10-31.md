**本报告第一节记的那批彩框样本能不能用？** 审计脚本 `logs/_audit_crit.py`，

  但只有 1 个反例，**不足以证明**那 18 次都是真的。

  其中 `4c2745…` 的两次（意识 4.30 → 投射 4.00 / 防守 4.10）、

  分别是 **0.270 / 0.353 / 0.343**，都远高于噪声带上限 0.11：
  19:31:01 意识、19:31:26 投射、19:51:31 投射。
