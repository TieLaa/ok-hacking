# 篮球少女：评分与六维属性的关系（32 个样本，33 张原图）

## 结论：技能品质三档

| 技能品质 | 分值 | 对应图标 |
|---|---:|---|
| 彩色 | 75 | 角色专属大招（头像图标） |
| 金色 | 50 | 金色 / 黄色图标 |
| 白色 | 25 | 蓝色、绿色图标（绿色是白色品质被动） |

```
评分 = 六维总和
     + 75 × 彩色技能数
     + 50 × 金色技能数
     + 25 × 白色技能数
```

白色 = 总技能数 − 彩色 − 金色。因为当前每个角色都恰好 1 个彩色，所以可以化简成：

```
评分 = 六维总和 + 25 × (技能总数 + 2 + 金色数)
```

- 彩色 3×25，白色 1×25，所以 1 个彩色比白色多 2×25；`+2` 就是这 1 个彩色的溢价，不是固定底分。
- 金色 2×25，每多 1 个金色，比白色多 25 分。
- 游戏里没有技能升级入口；技能是按品质定价，不是按等级。

## 关键校验

**真崎 6927：1 彩 + 4 金 + 3 白**

```
6577 + 75 + 4×50 + 3×25 = 6577 + 350 = 6927  ✅
```

**闪堂 6824：1 彩 + 2 金 + 4 白**

```
6549 + 75 + 2×50 + 4×25 = 6549 + 275 = 6824  ✅
```

由这两只联立：

```
6927: R + 4G + 3W = 350
6824: R + 2G + 4W = 275
相减: 2G − W = 75

2391: R + 3W = 150   （1 彩 + 3 白）
2749: R + 4W = 175   （1 彩 + 4 白）
相减: W = 25
代入: 2G − 25 = 75  →  G = 50
再代入: R = 150 − 75 = 75
```

得到 彩色 75 / 金色 50 / 白色 25。

## 实际意义（训练选择）

1. **训练前后的评分增量**：
   ```
   Δ评分 = Δ六维总和 + Δ技能品质分
   ```
   如果这次训练没有新增/替换技能，**Δ评分 就等于六维增量之和**。

2. 只看评分时，六维**完全等权**：+20 投射 和 +20 防守 对评分贡献一样。训练预览里把六个增量相加，就是评分增量。

3. 位置、绿色大拇指（优势属性）影响的是**成长率/获得量**，不是评分权重。所以「优先练优势属性」依然成立，但原因是同样一次训练能拿到更多点数，而不是这些属性更值钱。

4. 技能品质会影响评分：彩色 75、金色 50、白色 25。如果训练/事件能换技能，换一个金色等于 +25（相比白色）。

## 待确认

1. **彩色是否永远 75**：当前每个角色都恰好 1 个彩色，存档和截图都只能确定「彩色 + 白色被动 = 100」。如果游戏实际是彩色 100、白色被动 0，总评分不变；要拆开需要 2 彩 / 0 白被动的样本。
2. **金色是否永远 50**：目前 33 张图的品质检测和 3 个存档样本全部吻合，金色 = 50 已被数据钉死。
3. **非 0 成长率**：当前 32 张截图成长率全是 +0.0%。如果以后出现非 0 成长率，需要确认评分是否只取当前六维。
4. **评分档位边界**：C+/B 在 2500 附近，B/B+ 在 3000 附近，B+/A 在 3600 附近，S/S+ 在 7000 附近；A/S 之间还缺 4500–6150 的样本。
