# 属性优先级

这套规则只回答一个问题：**这一局里，什么属性该优先拿。**

实现集中在 `src/tasks/training/attributes.py`（纯函数，不读帧），
训练科目、商店、扭蛋、游戏厅共用它，避免各写一套判断。

## 1. 六维与需求属性

六维：**投射 / 弹跳 / 防守 / 体能 / 运控 / 意识**
（唯一来源 `src/tasks/ui/labels.py` 的 `TRAINING_SUBJECTS`）。

**队长打哪个位置，就优先补哪两个属性的短板。**
判定链：`指定队长` → `docs/roster` 里的 `position` → 位置表
（`src/tasks/training/attributes.py` 的 `POSITION_TARGETS` / `required_attrs`）。

| 位置 | 需求属性 |
| --- | --- |
| 控卫 | 运控 |
| 分卫 | 运控、防守 |
| 小前 | 弹跳、运控 |
| 大前 | 弹跳、防守 |
| 中锋 | 弹跳、防守 |

这张表在三个地方生效：

1. **训练科目**：需求科目 **+0.5 分**（`REQUIRED_BONUS`，约半个队友），
   和队友/器材同处一个分数里，不是硬性只练这两项。
2. **商店 / 扭蛋**：属性类内部子档抬一档 ——
   全属性 → **需求专项** → 推荐属性/专属饮料 → 奇妙秘籍 → 其他。
3. **游戏厅**：同品质里需求属性优先于其他属性。

边界：

- 查不到队长或位置 → 需求属性为空集，所有属性平等。
- 表里**没有**「体能」「意识」「投射」——它们不是任何位置的需求属性。
- 角色面板上的 `preferred`（角色推荐属性）**不参与判断**；
  代码只认位置。两者会不一致（36 个角色里 11 个完全不相交）。
- 需求属性只改变**选择顺序**，不改变实际训练/商品的收益数值。

## 2. 三条硬门槛

对**具体属性**判断时，先过这三条：

1. **缺口排除**：上限 − 当前值 < `缺口排除阈值`（默认 100）→ 不练、不买。
2. **减半门槛**：当前值 ≥ `属性减半门槛`（默认 1300）→ 分数（商店里是商品数值）×0.5。
3. **读不到不拦**：上限或当前值缺失时跳过对应判断，不因为 OCR 少一帧就停摆。

当前值/上限取自休息室快照（`parsers.snapshot_lounge`）；
上限按角色不同，一局内缓存（`_attr_caps`），新局清空。

**减半只作用于训练科目和商店属性商品**；扭蛋、游戏厅只做缺口排除。

## 3. 属性收益怎么算

事件二选一、加强训练选卡（`scoring.effect_value` / `_effect_ev`）：

- 「全属性 / 所有属性 / 全体」→ **×6**：`全属性+5` = 30 点。
- 写了几项属性就累加几项；没写属性名按 1 倍。
- 概率收益按 `收益 × 概率`，与确定收益取较大值。
- **精力/体力不进属性分**：只在属性打平后当次级比较，并按「上限−当前值」封顶。
- 纯回精力选项直接不选；训练等级按 100 分。
- 竖向三选一固定选第一个。

## 4. 各场景的落地顺序

### 4.1 训练科目（`handle_subject_select`）

候选池 = 有队友小人 **或** 金框/彩框已亮 **或** 当前已选。

分数 = 队友×1.0 + 装备×1.0 + 经理×2.1 + 金框×1.2 + 彩框×2.3 + 需求属性 0.5
（权重在 `strategy/params.json` 的 `scoring`）。

然后交给 `attributes.subject_priority`：
缺口排除 → 过门槛 ×0.5 → 按 `(分数, −当前值, −屏幕 y)` 排序。

- 满经验（MAX）只记日志，**不进分数**（框已经代表满经验，再算会重复计分）。
- 全部被排除 → 退回按原分数选，不做无意义点击。

### 4.2 商店（`pick_shop_item`）

先分大类：

1. 现金（老板的馈赠 / 大乐透）必拿；
2. 牛奶、精力（功能性商品，不按颜色筛）；
3. 其余按品质 **彩 → 金 → 紫**，蓝/白不买；
4. 同品质档位：器材教程/指导书 → 器材手册 → 教科书 → 属性。

属性类内部（`attr_sub`）：

**全属性 → 队长需求属性 → 推荐属性/专属饮料 → 奇妙秘籍 → 其他 → 随机效果**

- 属性卡过缺口排除；过减半门槛时数值 ×0.5。
- 「偶然 / 随机」是随机一个属性 +N，期望只有 1/6，排最后。
- 最后一周：整周不买器材/教科书/牛奶/精力；
  周日（最后一场比赛）只买属性商品，蓝/白也买。

### 4.3 扭蛋（`gacha_candidates`）

- 品质白名单（`扭蛋品质优先`，默认 彩 > 金 > 紫）；蓝/其他不买。
- **「笔记继承 / 球员位置」的彩色版本永远第一**（2026-11-15）：压过零用钱卡和
  品质分；所有流派的出行日第一步都先去步行街探卡池，这趟只买这两张。
- 流派专属卡：符合本流派优先，别的流派直接跳过（`card_style_target`）。
- 增加零用钱的卡：非训练流排最前（训练流不消费零用钱）。
- 属性档：**全属性 → 需求属性 → 推荐属性 → 其他 → 随机效果**。
- 缺口不足不买；「XX暴涨」第 7 周前不买（一次性 +250，但封掉一门训练）；
  清空精力卡只在精力 < 阈值（默认 30）时买；恢复卡过三类门槛。
- 最终排序：笔记继承/球员位置（彩色）→ 零用钱 → 品质 → 本流派专属 → 属性档
  → 增强款 → 队友多 → 非恢复优先 → 恢复价值 → 便宜。

### 4.4 游戏厅（`pick_arcade_card`）

- 只买「自动」+ 彩/金/紫；缺口不足不买。
- 品质 → 需求属性 → 队友多 → 奖励上限；0 元最先。

### 4.5 公园与技能

- 公园「划船」固定给属性+，**不区分六维**；去不去由精力缺口决定
  （训练流缺口 ≥ 70 野餐，< 70 划船，< 30 改打工）。
- 比赛技能三选一不吃六维取向：品质 → 道具图标 → 标签匹配
  （见 [规则](RULES.md) 第 8 节）。

## 5. 配置项

| 配置 | 默认 | 作用 |
| --- | --- | --- |
| `属性减半门槛` | 1300 | 当前值达到后，训练/属性商品收益减半 |
| `缺口排除阈值` | 100 | 离上限不足这个值，不再练/买该属性 |
| `商店购买策略` | 红包→彩→金→紫 | 关掉 = 只逛不买 |
| `扭蛋品质优先` | 彩、金、紫 | 只买这些品质，靠前的优先 |
| `扭蛋清空精力阈值` | 30 | 精力低于它才买清空卡 |

默认值的唯一来源是 `src/tasks/training/config_spec.py`（GUI 配置页由它生成）。

## 6. 已知边界

- 需求属性表只覆盖 4 项；体能/意识/投射没有位置加成。
- 「推荐属性」按**卡面字样**识别，不是逐字匹配队长的 `preferred` 列表。
- 减半不作用于扭蛋、游戏厅；它们只排除缺口不足的属性。
- 读不到当前值或上限时门槛不生效（宁可继续，不误停）。
